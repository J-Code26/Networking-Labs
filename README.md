# Networking-Labs

This repository is my organized documentation of my Cisco Packet Tracer labs, which will focus on networking, infrastructure, and security. This repository is here to document my progress as I study networking concepts, study for the CCNA, and prepare for being a networking professional. 

# Goals

- Strengthen networking fundamentals and knowledge
- Prepare for the CCNA (Cisco Certified Network Associate)
- Practice real-world troubleshooting
- Document labs and lessons
- Build a portfolio of practical networking projects

# Tools and Tech

- Cisco Packet Tracer
- Physical Switch
- Cat6E Cables
- Raspberry Pi Zero
- Git & GitHub
- CLI Configuration
- VLANs
- Routing and Switching
- Subnetting
- Network Troubleshooting

# Workflow

1. Study a networking concept
2. Design a Hand-Written topology digram with clear labels
3. Build the topology in Cisco Packet Tracer
4. Configure devices manually, research unlearned commands
5. Test connectivity, troubleshoot and document it
6. Break it, fix it
7. Upload the lab and notes to GitHub
